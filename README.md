# Ausblick – Clientes

Liste der möglichen Kunden von Ausblick: wen wir schon kontaktiert haben, mit **Telefonnummer, Ort und Webadresse**. Aufgebaut wie `work.castcomercial.com`.

- **Liste:** Name, Rubro, Telefon (antippen = anrufen), Ort, Web (antippen = öffnen), Status und letzter Kontakt (Datum, wer, was).
- **Status:** Sin contactar · Contactado · Interesado · Cliente · No interesado. Filter oben, Suche über alle Felder.
- **Kontakte:** Im Kunden „Registrar contacto“ → Datum, Notiz und Name des Geräts werden gespeichert. Der erste Kontakt setzt den Status auf „Contactado“.
- **Doppelte:** Beim Anlegen warnt die App, wenn Name, Telefon oder Web schon existieren.
- **Sort in / Alle:** Importierte Garagen starten unter „Sort in“. Dort pro Eintrag „✓ Existe“ (→ Alle) oder „✕ No existe“ (wird gelöscht, mit Rückgängig). Mit Telefonnummer oder eingetragenem Kontakt gilt ein Eintrag automatisch als existierend; selbst angelegte Kunden kommen direkt zu Alle. Adresse antippen öffnet Google Maps.
- **Kategorien:** pro Kunde beliebig viele (im Kundenfenster an-/abwählen oder neue anlegen), Filter neben der Suche. Eingebaut: „Cocheras / Parking lot / Parkplatz“ (`parking`) und „Peluquerías / Hairdressers / Friseur“ (`hair`), je nach Sprache angezeigt; eigene Kategorien so wie eingegeben. Alle Kunden, die vor dem 29.10.2026 angelegt wurden, haben automatisch „Parkplatz“.
- **„next to it“:** Checkbox unter der Telefonnummer, wenn die Nummer von einem Geschäft neben der Garage stammt; in der Liste als Etikett neben der Nummer. „(next to it)“ am Ende des Namens wird automatisch in die Checkbox umgewandelt.
- **Filter „Con teléfono“**, Liste seitenweise (100 pro Seite), Button „Ver mapa“ wenn in den Notizen ein Kartenlink steht.
- **Aufgaben (Kanban):** zweiter Bereich oben „Kunden / Aufgaben“. Spalten frei benennbar, verschiebbar, löschbar (nur leer), neue Spalten; Häkchen „gilt als erledigt“. Karten: Titel, Beschreibung, Zuständig, Fällig am (überfällig rot), Wichtig, verknüpfter Kunde, Kommentare. Ziehen mit der Maus oder per langem Drücken am Handy; alternativ Spalte im Aufgabenfenster wählen. Im Kundenfenster stehen die Aufgaben des Kunden und „+ Aufgabe für diesen Kunden“. Gespeichert in `tareas.json` im Daten-Repo.
- **Doku (Wiki):** dritter Bereich. Seiten mit Unterseiten (Baum links, am Handy Liste → Seite), Markdown mit Werkzeugleiste und Vorschau (Überschriften, fett/kursiv, Listen, Checklisten zum Abhaken, Zitate, Tabellen, Code, Links, `[[Seitenname]]` für Links zwischen Seiten), Volltextsuche, Verschieben, Verlauf der letzten 20 Versionen mit Wiederherstellen, Warnung wenn jemand anderes die Seite gleichzeitig gespeichert hat (nichts geht verloren, die andere Version bleibt im Verlauf), Entwürfe bleiben auf dem Gerät erhalten, direkter Link pro Seite (`#docs/<id>`). Gespeichert in `docs.json`. Bilder werden nicht hochgeladen – Links (z. B. Google Drive) gehen.
- **Finanzen (Einnahmen und Ausgaben):** wie „Rock La Ve“ in app.castcomercial.com. Monatsnavigation, oben die Monatssummen **Einnahmen** und **Ausgaben** und groß der **Saldo des Monats** (rot wenn negativ), darunter der Saldo insgesamt. Umschalter *Einnahmen | Ausgaben*, jeweils in zwei Listen **Einmalig** und **Fix (jeden Monat)** mit Summen. **+ Einnahme / + Ausgabe**: Betrag (z. B. `150.000` oder `80000,50`), Datum, Zweck, Kategorie (Vorschläge wie Abono mensual, Hosting, Software, Sueldos – frei überschreibbar), Kunde aus der Kundenliste und Notiz; „Speichern und weitere eintragen“. Fixe Einträge zählen jeden Monat ab dem Startmonat (am 1.); ein geänderter Betrag gilt ab dem Monat der Änderung, frühere Monate bleiben; „Nicht mehr bezahlt ab“ beendet sie. Antippen öffnet den Eintrag zum Ändern oder Löschen (mit Rückgängig). Die Suche durchsucht Einnahmen und Ausgaben. **Überblick**: Säulen je Tag (Einnahmen nach oben, Ausgaben nach unten) mit fortlaufendem Saldo, oder die letzten 12 Monate; Antippen zeigt die Beträge, dazu eine Tabelle und „Monat als CSV“ (Excel-tauglich). Direkter Link `#finanzas`. Gespeichert in `finanzas.json`.
- **Cauldron:** vierter Bereich zum Zusammenstellen der App für einen Kunden. Unten liegen unsere Anwendungen als Kästchen (Schichtplan, Restaurant, Zahlungen, QR-Anmeldung, Finanzen, Kunden, Aufgaben, Doku). Über den Stift auf jedem Kästchen lassen sich Name, Beschreibung, Basis-Repository, Datendatei, „Basis fertig“, Personal-Zugang, öffentliche Seite und Symbol ändern; „+ Anwendung“ legt neue an, „Anwendung entfernen“ blendet sie aus (mit Rückgängig), bei den mitgelieferten gibt es „Original wiederherstellen“. Die Änderungen liegen in `cauldron.json` und gelten für das ganze Team. Sie werden per Drag & Drop (am Handy kurz gedrückt halten) oder per Antippen in den Kessel gelegt. Dazu kommen Projektname, Kunde aus der Liste, Branche, Domain und der „Stil der Firma“: Website, Markenfarbe, Schriften, Ecken, Dichte, Tonfall und Logo, mit Live-Vorschau, wie die App beim Kunden aussieht. „Fusionieren“ ergibt den Bauplan. **Hosting „Repos (jetzt)“** (Standard): wie bei den bestehenden Kunden-Apps `<kurzname>-app` (öffentlich, GitHub Pages), `<kurzname>-data` (privat, eine Datei pro Modul) und `<kurzname>-team` falls Schichtplan dabei ist, mit Tokens, Adresse (`lucashcandido.github.io/<kurzname>-app` oder eigene Domain per CNAME) und Theme im APP-Block. **Hosting „Plattform (später)“** ist für den Marktstart gedacht: ein Tenant auf unserem Server, der Kunde bekommt nur einen Login. Das Theme hat in beiden Fällen dasselbe JSON-Format (`tenant_settings`), damit der Umzug später einfach ist. Dazu kommen eine Checkliste zur Inbetriebnahme (inkl. Términos y Condiciones und Datenexport), ein kopierbarer Bauauftrag und „Offene Schritte → Aufgaben“ fürs Board. Direkter Link `#cauldron`. Gespeichert in `cauldron.json`.
- **Export:** Configuración → Exportar lista (CSV, öffnet in Excel).
- **Sprachen:** Español, English, Deutsch. Beim ersten Öffnen nach Gerätesprache (sonst Spanisch), umschaltbar oben im Einrichtungsbildschirm und in der Configuración; die Wahl bleibt pro Gerät gespeichert. Die Daten selbst sind sprachunabhängig.

- **Design:** Ausblick Sistemas – schwarz/weiß wie Logo und ausblicksistemas.com (`#f6f6f6`, schwarzer Text), Logo-Zeichen als App-Icon (`icon-192.png`, `icon-512.png`, `apple-touch-icon.png`, `logo-mark-96.png`), Dunkelmodus invertiert.

## Daten und Zugang

- **Daten:** im privaten Repo `ausblick-clientes-data`, Dateien `clientes.json`, `tareas.json`, `docs.json`, `finanzas.json` und `cauldron.json`. Neuere Änderung gewinnt pro Kunde, Kontakte von zwei Geräten werden zusammengeführt. Offline-Änderungen werden später gespeichert.
- **Token:** Fine-grained Personal Access Token, der **nur** `ausblick-clientes-data` erreicht (Repository permissions → Contents: Read and write).
- **Code:** Wer die App zum ersten Mal mit dem Token einrichtet („Primera vez (token)“), bekommt einen 12-stelligen Code und die Datei `access.json` (Token mit AES-GCM/PBKDF2 aus dem Code verschlüsselt). `access.json` kommt in dieses Repo; alle anderen Geräte brauchen dann nur noch Name + Code. Ohne den Code ist die Datei nutzlos.
- **Token erneuert:** Mit dem neuen Token einmal „Primera vez“ machen und die neue `access.json` hochladen – die anderen Geräte holen sich den neuen Token automatisch, wenn der Code gleich bleibt (Configuración → Cambiar nombre o acceso → Primera vez, gleiches Gerät behält den Code).

## Einrichtung (einmalig)

1. Repo `ausblick-clientes` (öffentlich, für GitHub Pages) und `ausblick-clientes-data` (privat, leer) anlegen.
2. Diese Dateien nach `ausblick-clientes` pushen, Settings → Pages → Branch `main` / root.
3. Token erstellen (siehe oben), App öffnen → „Primera vez (token)“ → `access.json` herunterladen und in `ausblick-clientes` hochladen.
4. Optional eigene Domain (z. B. `clientes.ausblicksistemas.com`) per `CNAME`.
